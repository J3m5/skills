# Learn from authentic writing

Read this reference when asked to infer or refine the user's writing style,
rather than collecting samples for every ordinary draft.

- Inspect actual user-written passages. A published author name, approval, or
  user message role alone does not prove authorship: an assistant may have drafted
  or transmitted the text. Exclude passages whose origin is uncertain.
- Exclude assistant drafts, messages between agents, generated templates,
  quoted third-party writing, and automatic UI context. In response annotations,
  use the user's comments, not the selected assistant passages.
- Prefer examples suited to the medium and audience. Prompts can reveal wording
  preferences, but do not establish email layouts or signatures. Give explicit,
  recent corrections priority over inferred patterns.
- Keep samples in context and save only supported style guidance in the skill.
  Do not create a corpus or copy personal content into it. If retrieval is
  unavailable, use authentic supplied examples without claiming a retrieved match.

Use the shared voice guidance in `SKILL.md` when no additional style inference
is requested.
