# Review comments

Keep a comment proportional to the finding: the defect, its concrete consequence,
enough context to locate it, and a useful correction or request. A comment does
not need the full review report or the MR-description structure.

- State verified behavior clearly. Reserve uncertainty for facts that are still
  uncertain rather than weakening a demonstrated defect.
- Suggest a correction or ask for the desired result instead of giving orders.
  For a French colleague-to-colleague request, "Est-ce que tu peux le régénérer ?"
  is enough when the reader already knows the procedure.
- Keep exact identifiers and links needed to locate the finding. Include a
  command, reproduction, or test only when it helps assess or address the issue.
- Avoid speculative promises such as "should be enough" for a known action.
  Use a short paragraph for one finding and bullets only for distinct points.

Apply the shared publication rules in `SKILL.md`; preparing a review does not
authorize posting its comments.
